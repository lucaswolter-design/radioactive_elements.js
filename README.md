# ☢️ Radioactive & Toxic Elements — Sandboxels Mod

A Sandboxels mod that adds new radioactive and toxic materials with unique behaviors and visual effects.

## ☢️ Radioactive Elements

### Radium
- Green liquid
- Glows
- Releases visible radiation pixels

### Thorium
- Solid material
- Releases visible radiation pixels

### Cesium-137
- Blue powder
- Sticks to other materials
- Makes materials it contacts emit radiation
- Can affect nearby humans in the simulation

### Plutonium
- Radioactive solid
- Continuously releases radiation
- Occasionally produces a blue radiation flash
- The flash irradiates nearby materials

## ☣️ Toxic Elements

### Hexavalent Chromium
- Toxic solid
- Contact with a human can transform the human into Sandboxels' vanilla **Cancer** element

### Thallium
- Toxic solid

### Arsenic
- Toxic solid

## ☢️ Radiation

The mod includes visible radiation pixels that can be released by radioactive materials and spread through the simulation.

## 📦 Installation

1. Download `radioactive_elements.js`.
2. Open Sandboxels.
3. Open the **Mods** menu.
4. Add the `.js` file.
5. Reload Sandboxels.
6. Find the new materials in the element menu.
